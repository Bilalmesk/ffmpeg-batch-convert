        How watch works

        Hands-off batch conversion.

        1. 1

          Drop files into a watched folder, from a recorder or a network share.

        2. 2

          Settle — FFBatch waits until size and modified time stop changing.

        3. 3

          Convert — one batch at a time, using the settings on the Convert tab.

        Watchers run while FFBatch is open. Output folders and files already in the target format are ignored.
